What’s new in Rank Math SEO 1.0.283

Released: [Nov 25, 2026]

Tested up to WordPress 7.1.5

Changelog

  • Added Compatibility with the Divi 5 editor, so the SEO meta box now works in both Divi 4 and Divi 5.
  • Improved the handling of Content AI connection data and permissions.
  • Fixed the post Save button, which was not activated after changing the Redirect settings in the Advanced Tab of the Rank Math meta box.
  • Fixed the Links Per Sitemap option in the Sitemap settings, which could be set below 1 previously.
  • Fixed a UI issue with the SEO test category score badge.
