WooCommerce 11.3.0 Released

high confidence based on 1 community posts

What’s new in WooCommerce 11.3.0

Released: 2026-11-11

Active installations: 7,000,000

Tested up to WordPress 7.1.4

Requires PHP 7.4

Changelog

  • Fix – Add the missing space between sentences in the footer of back-in-stock notification emails. #69812
  • Fix – Align the customer stock notification admin screens with the order screens: even page gutters, a full-width action dropdown, rounded meta box corners, and a right-aligned submit button. #68851
  • Fix – Allow JavaScript detection to work with nonce-based Content Security Policies. #69811
  • Fix – Allow mobile zoom in the Core Profiler without triggering automatic input zoom. #68171
  • Fix – Allow the Order Fulfillments drawer to be scrolled with the mouse wheel on desktop. #69634
  • Fix – Allow turning off “Stock notifications” for a product that has never had the setting changed. #69497
  • Fix – Always apply the offline payment methods’ “Enable for shipping methods” setting at checkout, including on requests that reference an order. #68976
  • Fix – Analytics: add a Status > Tools tool, plus an inbox note pointing to it, that finds and re-imports orders whose partial-then-full refunds were counted twice in the Revenue report’s returns. #66505
  • Fix – Analytics: fix the custom date range calendar reading out the wrong date to screen reader users. #68514
  • Fix – Analytics: typed custom dates now follow the format shown in the field hint, so day-first locales get the right dates. #69701
  • Fix – Analytics: typed dates in the historical data import and advanced date filters now work in Czech, Croatian and other locales. #69745
  • Fix – Analytics report exports no longer lose rows or skip the download email when their batches finish out of order. #68955
