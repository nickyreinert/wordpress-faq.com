All-in-One WP Migration and Backup 7.114 Released

high confidence based on 1 community posts

What’s new in All-in-One WP Migration and Backup 7.114

Released: 2026-11-26

Active installations: 5,000,000

Tested up to WordPress 7.2

Requires PHP 5.3

Changelog

  • Improved access checks on admin pages. Credits to Gen Sato for reporting it
  • Some settings could break after import when they contained the database table prefix. Credits to Jakub Herman for reporting it
  • Search and replace could break or empty some stored settings. Credits to Jakub Herman for reporting it
  • Backups in subfolders could not be managed through the REST API

Previous releases

7.113

  • Restoring a backup on sites using SQLite Database Integration could leave the site on an empty or corrupted database

7.112

  • Scheduled backups stopping without an error on hosts that limit concurrent requests
  • Exported databases with empty binary or blob values could not be read by tools outside the plugin
