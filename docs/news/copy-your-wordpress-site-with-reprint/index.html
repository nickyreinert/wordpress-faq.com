Copy Your WordPress Site with Reprint

Reprint is a free, open-source, PHP-based tool that copies a WordPress site’s files and database. The plugin is available in the WordPress.org Plugin Directory, along with the command-line client used to copy the site. WordPress has long let you export your posts and pages.
