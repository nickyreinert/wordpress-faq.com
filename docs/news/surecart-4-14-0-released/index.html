SureCart 4.14.0 Released

high confidence based on 1 community posts

What’s new in SureCart 4.14.0

Released: November 26th, 2026

Active installations: 70,000

Tested up to WordPress 7.2

Requires PHP 7.4

Changelog

  • New: International Shippo shipping labels now include a customs declaration, so they can be bought. Products and variants have new HS code, country of origin and manufacturer code fields.
  • New: Each price can set its own proration method, which decides how much credit customers get for their current plan when they switch to that price. Admins can override it for a single immediate update on the subscription edit screen.
  • Improvement: Removed Premium tags and upgrade prompts from the WordPress admin, so every feature can be used without unlocking it first.
  • Improvement: New installs use the customizable, block-based Instant Checkout by default. Existing stores keep their current setting.
  • Improvement: The setup guide’s “Add a product” step now completes for stores that keep priced products as drafts and sell through buy links.
  • Improvement: Failed media uploads now show the reason, for example when the file is too large, and the media library links to the storage limits.
  • Improvement: The proration line item is now labeled “Proration Credit” in orders, invoices and the customer dashboard.
  • Improvement: Blocks and admin screens are ready for React 19.
  • Fix: Closing a Stripe QR payment window (such as PayNow, PromptPay or WeChat Pay) without paying showed the order success screen.
  • Fix: Quick Add buttons, product review buttons and other blocks could stop working on WordPress 7.2.
  • Fix: Tutor LMS students could get duplicate enrollment emails after a purchase.
  • Fix: A purchase on a Classic buy page could leave an extra test mode draft checkout.

Previous releases

4.13.2 — November 20th, 2026

  • Fix: Searchable dropdown selectors in the admin could stop working on WordPress 7.1.5.

4.13.1 — November 16th, 2026

  • New: Duplicate coupons, order bumps and upsell funnels from their list or edit screen. Duplicated coupons don’t copy promotion codes, and duplicated upsell funnels start disabled.
  • Improvement: The “No Thanks” opt-out link under the checkout email field can now be changed under Settings → Abandoned Checkout → GDPR Settings.
  • Improvement: Shop Managers can now open SureCart Settings and manage store settings. Admin-only tabs such as Connection, Advanced, Payment Processors and AI Assistants stay hidden.
  • Improvement: Shipping labels can be created without a recipient phone number, because some carriers (such as USPS domestic) don’t need one. A note recommends adding it, since most carriers do.
  • Fix: Customer links that include a page path, such as checkout or subscription links from SureCart-powered apps, opened the customer dashboard home instead of the requested page since 4.11.0.
