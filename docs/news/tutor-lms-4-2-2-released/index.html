Tutor LMS 4.2.2 Released

high confidence based on 1 community posts

What’s new in Tutor LMS 4.2.2

Released: 24 Nov, 2026

Active installations: 90,000

Tested up to WordPress 7.1.5

Requires PHP 7.4

Changelog

  • New: Added a Membership tab to display all courses purchased through membership plans. (Pro)
  • Update: Assignments, comments, and Q&A now show users’ WordPress display names instead of their usernames.
  • Update: Improved translation coverage and compatibility.
  • Update: Optimized overall performance and implemented additional security enhancements.
  • Fix: Fixed an issue where Range-type questions became inaccessible and prevented learners from exiting quizzes after switching from the Modern to Legacy layout. (Pro)
  • Fix: Fixed incorrect learner profile links in Instructor Analytics. (Pro)
  • Fix: Corrected inaccurate refund and discount totals in the Frontend Analytics graph. (Pro)
  • Fix: Prevented unapproved and blocked instructors from submitting withdrawal requests or accessing restricted dashboard sections. (Pro)
  • Fix: Fixed an issue where minimum coupon requirements could be bypassed during checkout.
  • Fix: Fixed a division-by-zero error that occurred when processing orders with a total of $0.
  • Fix: Fixed an issue where clearing a logged-in device from the WordPress login page did not work as expected. (Pro)
  • Fix: Fixed a layout alignment issue caused by category text.

Previous releases

4.2.1 — 09 Nov, 2026

  • Update: Improved WPML compatibility. (Pro)
  • Fix: Resolved an issue where post content disappeared when switching from a page builder to the native WordPress editor.
  • Fix: Resolved an issue where period filters were not applied correctly to the earnings graph and dashboard reports. (Pro)
  • Fix: Corrected inaccurate course counts in the course export process. (Pro)
  • Fix: Resolved an issue where students could enroll in paused courses under certain circumstances. (Pro)

4.2.0 — 27 Oct, 2026

  • New: Added REST API authentication with personalized access tokens.
  • New: Added endpoint-level authorization to ensure REST API operations follow user roles and capabilities.
  • Update: API key permissions for Read, Write, Delete, and All actions are now enforced across Tutor LMS REST API routes.
  • Update: Sensitive learning content routes now require valid enrollment, public access, or instructor/admin permissions. (Pro)
  • Update: Quiz answers are now verified server-side in Reveal Mode to prevent answer exposure.
