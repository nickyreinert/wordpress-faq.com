Community Q&A

What is WordPress Full Site Editing?

Full Site Editing is a collection of features that allow users to design their entire website using blocks, including headers, footers, and templates.

Is Gutenberg the same as Full Site Editing?

Gutenberg is the block editor project that powers Full Site Editing, serving as the underlying technology for the modern WordPress design experience.
