Community Q&A

What is WordPress Full Site Editing?

Full Site Editing (FSE) is a collection of features that allow users to edit their entire website, including headers, footers, and templates, using blocks.

Is Gutenberg the same as a page builder?

Gutenberg is the native block editor for WordPress. While it functions similarly to page builders, it is integrated into the core software.

Should I use Gutenberg or a third-party page builder?

Gutenberg is recommended for native performance and long-term compatibility, while third-party builders may offer more advanced design features.
